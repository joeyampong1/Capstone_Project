# Python Requirements for Face Verification

This project requires Python and specific libraries to run the automated face verification feature (comparing the selfie against the uploaded ID).

## Requirements
- **Python 3.8+** installed on the server.
- **PHP `shell_exec`** must be enabled in `php.ini` (not disabled for security).
- **System dependencies** (Linux/Debian/Ubuntu):
  ```bash
  sudo apt-get update
  sudo apt-get install python3 python3-pip cmake build-essential
